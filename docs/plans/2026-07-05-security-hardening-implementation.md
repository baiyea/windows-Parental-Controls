# 未成年电脑时间管理器漏洞修复记录

## 范围

本次修复排除配置文件防篡改、密码明文存储、配置关闭可信时间等问题。

修复代码层面的可执行问题：

1. 普通锁屏没有传入休息倒计时，导致锁屏窗口可能无法自动关闭。
2. 夜间限制结束后状态机会切回工作态，但锁屏窗口可能仍停留。
3. 程序重启后没有恢复未结束的工作计时，导致重启即可刷新使用时间。
4. 单实例锁使用固定 TCP 端口，普通进程占用端口即可阻止程序启动。
5. 启动时只要存在 `update.bat` 就执行，缺少来源校验。
6. 开发测试时真实锁屏会影响调试，需要可配置的提醒式 debug 锁屏模式。

## 做法

- 用回归测试固定上述行为。
- 锁屏窗口增加控制器关闭路径，锁屏状态退出时主动关闭窗口。
- 新锁屏时传入休息剩余秒数。
- 启动时恢复 `work_end_time`，过期则立即锁屏。
- 单实例锁改用 Windows 命名互斥量，避免端口抢占。
- 更新脚本增加配套标记文件，只执行程序自己生成的待更新脚本。
- 配置增加 `debug_mode`，开启后仍进入锁屏状态和保存计时状态，但不显示全屏锁屏窗口，只发送提醒。

## 验证

- 运行新增单元测试确认修复行为。
- 运行现有测试防止夜间限制和可信时间逻辑回归。
- 运行 `ruff check .` 检查静态问题。
