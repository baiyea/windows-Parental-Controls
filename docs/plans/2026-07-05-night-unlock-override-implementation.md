# 夜间密码解锁临时放行实现记录

## 背景

夜间限制期间输入密码后，程序会从 `LOCKED` 回到 `WORKING`。但监控循环下一秒仍会检测到当前处于夜间限制时段，并再次触发强制锁屏。

## 目标

把夜间密码解锁定义为“家长临时授权”，默认放行 30 分钟，而不是永久关闭夜间限制。

## 配置

在 `restrict_night_hours` 下新增：

- `password_unlock_grace_minutes`: 密码解锁后的夜间放行分钟数，默认 30。
- `override_until`: 当前夜间放行截止时间，格式为 `%Y-%m-%d %H:%M:%S`，默认 `null`。

## 行为

1. 夜间锁屏中输入正确密码后，写入 `override_until = 当前可信时间 + password_unlock_grace_minutes`。
2. 夜间限制判断分为“是否处于夜间时段”和“夜间限制是否实际生效”。
3. `monitor_loop` 和启动检查使用实际生效判断，放行期间不重复锁屏。
4. 放行过期后，如果仍处于夜间时段，下一轮监控再次锁屏。
5. 放行状态写入配置，程序重启后仍可延续本次授权。
